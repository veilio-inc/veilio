# What veilio-guard covers, and what it does not

This is the statement Veilio publishes about the Claude Code guard. Each claim names the test that holds it; `tests/guard/coverage.test.ts` fails if a test named here is missing. The "Not covered" list states what the guard cannot do.

It applies to Claude Code 2.1.287 or later, with the plugin installed and its mod loaded. That means the terminal CLI, the Code tab of the Desktop app, the VS Code extension's chat panel, `claude -p` and the Agent SDK. Other agents (Cursor, GitHub Copilot, Codex) are not covered by this plugin. Tested on macOS and in Linux CI; Windows is untested.

The interactive walk in a terminal was done on 2026-10-03 (the band, the redrawn replies, tool rows and diffs, `/veilio`, and the transcript on disk holding placeholders only). Windows has not been checked.

## Not covered

- **Without the mod, nothing is guarded.** That includes Claude Code before 2.1.287, a session started with `--safe-mode` or `--bare`, and your own `disableAllHooks` setting. In those cases Claude reads raw code. An organisation that runs the guard through managed settings keeps it running under a user's `disableAllHooks`.
- **The first message on a project with no map.** Names you type that the guard has not seen yet in a file go to the model as you typed them. Running `veilio scrub` on the project first, or reading the files once, builds the map.
- **Names that appear only in output.** Shell output and search results are scrubbed only with names the map already has. A name the model has never read in a source file passes in them.
- **Programs that open files themselves.** The raw-only check looks at the files a command names, including a flag's value such as `--env-file=.env`. A script that opens `.env` itself, or `grep -r` run in the shell over a directory, is not refused. Credentials in what it prints are removed, but plain values such as a database host are not. Strict mode, a later release, will close this with an operating-system sandbox.
- **Clearing the map while a session is open.** The guard puts back every entry it knows on its next save, so `veilio map --clear` run while Claude Code is open is undone. Clear the map with no session open.
- **Two programs saving the map in the same instant.** The guard reads the file, merges and writes it, but Claude Code gives a mod no atomic write. Entries another program drops are put back on the guard's next save, and a placeholder that would mean two names is detected and masked again.
- **Everyday words.** Words from string literals that are everyday words (`the`, `keep`) are masked only inside source files, where the engine finds them in a literal; in output and prompts they are left as written. One shaped like a name (`customer_refunds`, `apiV2`) is masked everywhere. Code names that are also English words (`total`, `update`) are masked everywhere, so a prompt naming them matches the code Claude reads; in a log or a listing that shows as a placeholder.
- **Prose in comments.** The engine masks identifiers. Comment text is left as written, apart from names the map already has.
- **A failing failure handler.** If the `.catch` handler itself fails, Claude Code keeps the tool's result. The handler returns a constant and does no work, so this is not expected.
- **Timeouts.** A scrub that overruns Claude Code's 10-second budget takes the same `.catch` path as one that throws. The kit can't force a timeout in a test, so there is no test of its own.
- **Images and PDFs** are withheld, not scrubbed.
- **Claude Code's own fixed texts.** Some texts Claude Code adds itself, such as the advisor tool's instructions, do not pass through the guard's hooks. They hold no project code, but a project name that is also an English word (`reconcile`) can appear in them as written.
- **Searches reveal parts of names.** A search for a word matches inside the real names, so a match on a line where Claude sees only placeholders tells it that one of those names contains the word (`grep settle` matching the line of `settledTotal`). The names themselves stay masked.
- **What Claude says it saw.** Your view is redrawn with the real names, so when Claude explains that it only sees placeholders, the placeholder it quotes is drawn as the real name too. Ask it to spell the name letter by letter to see what it received.
